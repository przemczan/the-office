# 12 · The Stage interpreter: Start, Agent and Script Stages, loops

Status: done

## Goal

The Pipelines module runs a Ready Task: the user starts it (or is told why not), and an interpreter of the Task's Pipeline data walks its Stages. Agent Stages run a session briefed from the record and end with a flat result envelope and a Handover note; Script Stages run a Project command with no model call; The Office commits each Stage's work and checks git after it. On-failure loops, round limits and budgets ask the user, never fail silently. Gates and Publish come in task 14; Stop, Pause and barge-in in task 13.

- [x] The interpreter is one generic walk over Stage data: no class or method per Stage, each Stage's run state owned by its own run record. Check: scripted-adapter tests, including an invalid result corrected once.
- [x] A Stage of another Role than the session's is a hand-off with a Brief, through the Context policy (moved here from task 09, whose chats never change person; agreed with the user). Check: a scripted-adapter test of the hand-off at a Stage boundary.
- [x] After each Agent Stage The Office commits its work with a message from its result and Handover note, checks HEAD and the branch are where it left them, and ends the session's leftover processes. Check: a test where the Agent moves HEAD, and one that leaves a process running.
- [x] A Script Stage runs its command in the worktree with the Project's environment, re-runs a failing test command once before failing it, filters its output, records the result, and restores the worktree after test runs. Check: tests with a flaky and a failing command.
- [x] "On failure go back to Stage X at most N times" loops with the error in the next Brief; a round limit or a failure with no retries left opens a Decision for the user (allow more rounds, continue with the issues recorded, guidance for one more round, drop); a budget limit, checked before every engine call against all of the Task's usage, opens a Decision to raise it. Check: scripted-adapter tests of each.
- [x] An optional Stage is skipped when every statement of the Definition of Done is already reported met; the Task is Done when the Pipeline completes with the Definition of Done met, and asks the user when it isn't. Check: tests of both.
