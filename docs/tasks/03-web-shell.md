# 03 · Web shell: design system, themes and A3 · Desk

Status: in progress

## Goal

The web app every surface lives in: the design system available as typed React components, the theme layers with Light and Dark, and the A3 · Desk shell from the click-through (rail, top bar, status strip frame, panels), with routing, the API client and the WebSocket connection. Surfaces fill it from task 04 on.

## Definition of Done

- [ ] `apps/web` imports every design-system component from `packages/ui`, typed by the shipped `.d.ts`; nothing in `apps/web` imports `design-system/` directly. Check: `npm run verify` with the adherence lint on `apps/web`.
- [ ] The shell matches the click-through's A3 · Desk at full width, two panels and one panel. Check: Playwright screenshots of the shell at three widths, side by side with the click-through's.
- [ ] Light and Dark switch at runtime and follow the system by default; components use aliases only. Check: Playwright screenshots in both themes; a grep for raw colours in `apps/web` finds none.
- [ ] The rail links to the five surfaces; Now, Work, People, Projects and Settings each render an empty page with its title. Check: Playwright walks the rail.
- [ ] The web reconnects to the WebSocket after the service restarts, and shows that it is reconnecting. Check: restart the service with the page open.
