# 10 · Work: Ideas, Tasks, the board and Attachments

Status: in progress

## Goal

The Work module and surface: Ideas captured in seconds from the top bar and shaped into Tasks; Tasks with their states, priority and manual order on a board by state; Attachments added by the user; and the Task page's record beside its conversation, ready for planning in task 11 and running in task 12. Chats gain the Office tools that read Work and capture Ideas.

## Definition of Done

- [ ] "Idea" in the top bar captures an Idea (title, optional notes, Project or Office-wide) from any page in a few keystrokes. Check: Playwright captures one from Now and one from a Task page.
- [ ] Shaping an Idea makes a Task in a chosen Project in Backlog, keeps the Idea as the Task's origin and moves its Attachments; dropping an Idea keeps it readable as dropped. Check: shape one, drop one.
- [ ] The Task states and their rules hold: Backlog → Planning → Ready → In progress → Done, Waiting on you and Paused as side states, Dropped as the exit; Ready needs a Plan and a Definition of Done. Check: domain tests of every allowed and refused transition.
- [ ] The board shows Tasks by state with their Project mark, priority (three levels) and manual order kept per Project; dragging reorders and the order survives a reload. Check: Playwright drags a card.
- [ ] The user adds an Attachment (a Markdown document, an image, a file or a link) to an Idea or a Task; files live in the Office data directory with metadata in Postgres. Check: add one of each and open them.
- [ ] The Task page shows the record (Definition of Done, Plan, Stages of its Pipeline, Attachments, the origin Idea) beside its conversation, with the Changes tab arriving in task 14. Check: open a Task.
- [ ] In a chat, the Planner reads a Task or an Idea, captures an Idea and creates a Task in Backlog through the Office tools, and the person's page lists their Tasks under Work. Check: ask the Planner in chat on the Test Project.
