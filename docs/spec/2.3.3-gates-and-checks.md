# 2.3.3 Gates and checks

Covers: Gates, Continue, Send back and notes, the Definition of Done check, statements Out of reach, reports across Stages, a Gate just before Publish.

## Gates

- At a Gate the user continues, with notes or none, drops the Task, or sends the work back with feedback.
- A Gate shows the diff, results, Attachments and screenshots ([Stage kinds](2.3.1-stages.md#stage-kinds)).

## Send back

- The user sends the work back to any Stage the walk ran before the Gate, but a Gate or a Publish (whose work has already left the workstation), using no round.
- An Agent Stage is briefed with the feedback.
- A Script Stage can't read it, so it simply runs again and the walk goes on from there by its routes; the feedback is kept on its run and shown on its row.
- It is no route and no cycle ([Validation](2.3.2-flows.md#validation)).

## Gate notes

- Notes the user continues with, such as which version of a design to build, are kept on the Gate's run and shown in its Stage history.
- Every later Agent Stage is briefed with them under its earlier Stages.
- They are offered only when an Agent Stage comes after the Gate, and refused otherwise, as nobody would read them.
- Blank notes are plain Continue.

## Defaults

### Statements Out of reach

- An Agent Stage's done result may list Definition of Done statements it can't verify where it works, each with why.
- Reports count across Stages as for Reported met: a statement stays Out of reach, with the latest why, until a later report meets it.
- When the Definition of Done check finds it not reported met, the Decision lists what the Stage it would run again can address apart from what is Out of reach, for the user to check.
- The Decision recommends running that Stage once more while it can address any, that round's Brief naming only those.
- It recommends calling it met (Call it met and publish before Publish, Mark the Task Done at the end) when the Stage can address none, the user checking those statements first.

### Reports count across Stages, and the check runs before Publish

- A Definition of Done statement is Reported met once any Agent Stage's done result reports it met, and stays met when a later result leaves it out.
- A result takes one back only by listing it in its own "no longer met" list, such as a regression found in review.
- A result naming a statement the Definition of Done doesn't have, or one both met and no longer met, is refused for the Agent to correct.
- The Brief marks the statements Reported met so far.
- The Definition of Done check runs as the walk reaches a Publish Stage that isn't the Pipeline's first, before it runs, so an unmet statement is asked about before anything is pushed or merged:
  - One more round runs the last Agent Stage the walk ran before that Publish, never Resolve (or the Stage the walk ran just before it when there is none), and the check runs again when the walk next reaches Publish.
  - Call it met and publish runs Publish, and the Task completes as its walk reaches End, with no second check.
  - Drop the Task drops it.
- Resolve's Stages going back to Publish after a conflict don't check again.
- A walk that reaches End with no Publish run after its first Stage is checked as it reaches End, with Mark the Task Done.
- Resolve's Stages, put before a Publish that conflicted, don't make it later than first.
- A Decision recorded where the check ran before (on a Publish run, past the last Stage) is kept where it is, open or answered, even when nothing is unmet by the new rule.

### A Gate just before Publish is the check

- A Gate with no Agent Stage between it and the Publish Stage after it, on any path of routes between them, is the Definition of Done check for that Publish, so the user is asked once.
  - Script Stages may stand between; Resolve's Stages don't count.
- Continue there calls it met, as Call it met and publish does: Publish runs and the Task completes with no further check.
- Send back stands for one more round, the user choosing the Stage and giving feedback.
- Drop drops the Task.
- While statements aren't Reported met, that Gate lists them, an Out of reach one with its latest why, and its Continue reads "Continue and publish anyway".
- An Agent Stage after the last Gate, whose report may change what is met, or no Gate before Publish, leaves the check before Publish as it is.
- A Definition of Done Decision already recorded on a run is replayed where it is.
