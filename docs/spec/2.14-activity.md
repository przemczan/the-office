# 2.14 Activity

Covers: Activity, what it lists, running and ended items, since, seen per user, the count, live updates, Ended items kept, Seen items kept.

## Activity

- **Activity** is everything The Office is doing, in one list, gathered afresh on each read from the modules that own each part ([5.3 Activity](5.3-modules.md#activity-reads-through-ports-of-its-own)).
- It is read with `GET /activity`, which answers the signed-in user's items and their count.
- Each item has:
  - its kind ([What is listed](#what-is-listed));
  - a stable id, new when the item comes again, such as a Task's later failure;
  - its Project;
  - a title;
  - since ([Since](#since));
  - whether it has ended, and when ([Running and ended](#running-and-ended));
  - where it leads: a Task, an Initiative, a Project or a page on the Project's code host.
- The running items come first, then the ended ones; within each, the newest first.

## What is listed

- **Task**: a Task In progress, Waiting on you or Paused; once Done, as ended.
- **Onboarding run**: a Project's Onboard Task ([2.1.1](2.1.1-projects.md#onboarding-a-project)), listed once, as an Onboarding run rather than as a Task.
- **Failed Task** and **Stopped Task**: a started Task whose current Stage, the one run last, failed or was stopped ([2.3.1](2.3.1-stages.md)), with no Decision open on it. With a Decision open, it is listed as a Task, since the Decision asks for the user already ([2.4.2](2.4.2-decisions.md)).
- **Test instance**: Building, Running, Built or Failed ([2.12](2.12-test-instances.md#test-instance-states)); a Stopped one isn't listed.
- **CI run**: each Project's recent CI runs, with their status and their page ([2.1.6](2.1.6-board-and-search.md#the-ci-tab)).
- **Environment check**: each Project's check running now, else its last finished one ([5.5](5.5-git-and-isolation.md#the-projects-environment)).
- **Connected device**: every device not Disconnected ([2.13 States](2.13-connected-devices.md#states)).
- **Pull request ready to merge**: an open pull request The Office opened that is mergeable, its checks passing or none, and read on its last refresh ([2.3.4](2.3.4-publish.md#the-office-records-the-pull-requests-it-opens-and-refreshes-them-every-minute)).

## Running and ended

- An item has **ended** when:
  - a Task or an Onboarding run is Done;
  - a test instance is Built or Failed;
  - a CI run is no longer queued, waiting or running;
  - an environment check has finished, passed, failed or stopped;
  - a Failed or Stopped Task is listed at all.
- Every other item is running.
- Connected devices and pull requests never end: they leave the list once Disconnected, or once merged or closed.
- An ended item leaves the list once it ended over [Ended items kept](#ended-items-kept) ago, seen or not.

## Since

- Every item carries **since**: when it entered the state it is in.
- A Task: its last change into its state, else when it was made; once Done, when it was Done.
- A Failed or Stopped Task: when its Stage run ended.
- A test instance: when it was launched, when it began Running, or when it ended.
- A CI run: when it started, or its last update once it has ended.
- An environment check: when it started, or when it finished.
- A Connected device: when it connected.
- A pull request: when it was last checked, else when it was opened.

## Seen per user

- An ended item stays listed for a user until that user has seen it, with `POST /activity/seen` and the items' ids.
- What a user has seen is kept per user, in the database, so it holds in every browser they sign in from; other users still see the item.
- A running item is never left out for having been seen: its ended form has an id of its own.
- What was seen is forgotten after [Seen items kept](#seen-items-kept), well past the items it hides.

## The count

- `GET /activity` answers a count for the status strip: the running items and the ended items the user hasn't seen, which is every item listed for them.

## Live updates

- A change in any source (a Task's state, a Stage run, a Decision, a test instance, CI runs, an environment check, a pull request, a Connected device), and a user marking items seen, send `activity.changed` on the event stream ([5.3](5.3-modules.md)).
- It carries nothing: what was seen differs per user, so each browser reads `GET /activity` again.
- A burst of changes sends one, and one more for those that came while it was sent.

## Defaults

### Ended items kept

- An ended item stays listed for at most 7 days after it ended, seen or not, so a user who never opens Activity isn't left with an endless list.

### Seen items kept

- What each user has seen is kept 30 days, and forgotten each time a user marks items seen.
