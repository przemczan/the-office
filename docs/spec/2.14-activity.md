# 2.14 Activity

Covers: Activity, sessions and when they are active, activities per subject, The Office's sessions, other running work and what each kind lists (Action runs among them), since, the count, live updates.

## Activity

- **Activity** is everything The Office is doing right now, gathered afresh on each read from the modules that own each part ([5.3 Activity](5.3-modules.md#activity-reads-through-ports-of-its-own)).
- It is read with `GET /activity`, which answers the signed-in user's activities, the other running work and their count.
- It lists only what is running or waiting now: nothing that ended, and nothing seen or unseen.

## Sessions

- A **session** is the work of one person, or of The Office itself, on one Thread: a Stage's, a Consultation's, an Initiative Thread's or a chat's.
- It is **active**, and so listed, while:
  - its Agent is taking a turn: its state is **working**;
  - or a Decision in its Thread is open: its state is **waiting**, on that Decision, or on its Consultant when the Decision was put to one ([2.4.2](2.4.2-decisions.md));
  - or, for a chat only, it has a reply the user hasn't seen yet: its state is waiting on that reply.
- It leaves the list as soon as none of these holds.
- A session carries its person (by their Role), its kind (Stage, Consultation, Thread, chat or Gate), the Stage it is at when it is a Stage's, its state, what it waits on with the Decision's one-line question when there is one, and since.
- Chats listed are the signed-in user's own, never another user's: a chat is the user's own when they wrote its latest user message, and an older chat with no recorded writer counts as theirs.
- A Consultation in a chat is listed only for the user who owns that chat.

## Activities

- Active sessions are grouped into **activities**, one per subject:
  - a **Task**: its Stage Threads, the Consultations on it, its own Threads and The Office's sessions;
  - an **Initiative**: its shaping and planning Threads;
  - a **chat**: one Thread of a person's chat.
- A Consultation belongs to the activity of the Thread that asked it: on a Task, the Task's; from a chat, that chat's; from an Initiative's Thread calling on no Task, the Initiative's.
- An activity carries every active session on its subject, the people working on it with each one's state.
- An activity leads to its Task, its Initiative or its chat, and is titled by it; a Task's activity carries its Project and its Initiative.
- A Paused, queued or Ready Task with no active session is not listed.
- The activities come newest first by their since.

## The Office's sessions

- **A Gate**: a Task waiting on you at a Gate ([2.3.1](2.3.1-stages.md)) is a waiting session of The Office, named after the Gate, with no person.
- **A Stage with no Agent**: a Task running a Script or Publish Stage now is a working session of The Office, named after the Stage.

## Other running work

- Other running work is listed below the activities, newest first, and only while it runs or stalls.
- **Onboarding run** and **Run environment set-up**: a Project's Off-board Tasks ([2.1.3](2.1.3-tasks.md#off-board-tasks)).
  - Each is listed once, as its own kind.
  - It is listed while Queued (with its place and short reasons), In progress, Waiting on you, Paused or Failed (a Stage out of tries, its Decision open), never once Done or Dropped; one made before and still Ready isn't listed.
  - It carries the Stage it is at or failed at, and its tokens: every Stage run's, counted as Now's today's tokens counts them.
- **Failed Task** and **Stopped Task**: a started Task whose current Stage, the one run last, failed or was stopped ([2.3.1](2.3.1-stages.md)), with no Decision open on it; it is listed while it stays so. With a Decision open, its session is listed instead ([2.4.2](2.4.2-decisions.md)).
- **Test instance**: Building or Running ([2.12](2.12-test-instances.md#test-instance-states)).
- **CI run**: a Project's CI run queued, waiting or running, with its status and its page ([2.1.6](2.1.6-board-and-search.md#the-ci-tab)).
- **Environment check**: a Project's check running now, of its base branch or a Task ([5.5](5.5-git-and-isolation.md#the-environment-check)).
- **Connected device**: every device not Disconnected ([2.13 States](2.13-connected-devices.md#states)).
- **Action run**: a Project command run while it is running ([2.15](2.15-actions.md#states)), titled with its Action and what it runs from, naming who started it, and leading to its Project's Actions; a Test target run is listed as its test instance and a Workflow run as its CI run, never twice.
- Each item has a stable id, its Project, a title, since and where it leads: a Task, an Initiative, a Project or a page on the Project's code host.
- An item leaves the list as it ends; an Action run's Outcome is told by its Notification ([2.7](2.7-notifications.md#action-run-outcomes)) and its log is kept in its Action's history ([2.15](2.15-actions.md#history)).

## Since

- A session: when its turn began, its Decision was put, its reply came, or its Gate or Stage began.
- An activity: the earliest of its sessions'.
- A Failed or Stopped Task: when its Stage run ended.
- An Onboarding run or a Run environment set-up: when it entered its state.
- A test instance: when it was launched, or when it began Running.
- A CI run: when it started.
- An environment check: when it started.
- A Connected device: when it connected.
- An Action run: when it started.

## The count

- `GET /activity` answers a count for the status strip: the activities plus the other running work, which is everything listed for the user.

## Live updates

- A change in any source sends `activity.changed` on the event stream ([5.3](5.3-modules.md)):
  - a session starting or ending, starting or stopping to wait, or a chat's reply being seen;
  - a Task's state, a Stage run, a Gate, a Decision, a test instance, CI runs, an environment check, a Connected device or an Action run.
- It carries nothing: the chats listed differ per user, so each browser reads `GET /activity` again.
- A burst of changes sends one, and one more for those that came while it was sent.
