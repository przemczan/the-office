# 2.8 Fire alarm

From [15](../../.scratch/the-office/issues/15-fire-alarm.md) (tier 2).

- Office-wide only. **Sound the alarm** stops every Stage, waiting Task, Consultation and background work at the next safe point (hard stop after 60 s); running git operations finish; nothing new starts.
- Chats stay open, but no Agent runs tools unless the user lifts that for one Thread.
- **All clear** first lists on Now what will resume, how (warm or fresh with a brief) and at what cost, with Hold and Drop per Task; then everything resumes through the Context policy.

## Defaults

Gaps no ticket settled, filled with the simplest choice consistent with the tickets and accepted by the user; each says when.

- **Acting during the alarm** (the user's answer of 2026-10-29): an answered Decision or a Gate action is recorded, but nothing walks until the all clear; Start joins the queue with the reason "The fire alarm is on.", released after the all clear. (added while building tier 2)
- **The alarm's details** (chosen while building tier 2, told to the user on 2026-10-29): Sound the alarm needs no confirmation; it outlives a restart; a Script Stage stops at once and runs again from its start; a lift for one Thread ends at the all clear; Hold leaves a Task paused as the user's own Pause; the cost is counted in tokens from the Context policy. (added while building tier 2)
