# 1. The user's day

Covers: morning, during the day, while work runs, token efficiency.

## Morning

- The user opens The Office in the browser.
- **Now** shows what needs them: Decisions, Gates, messages from people.
- Now shows what is running: Task · person · Stage · time in Stage.
- Now shows what happened since they left.
- Now shows today's tokens with the 5-hour window.
- The user answers what waits, in place.

## During the day

- A thought becomes an **Idea** in seconds from the top bar.
- When an Idea is worth doing, the user shapes it into a **Task** or into an **Initiative**.
- A Task is planned in a thread with the Planner (Plan, Definition of Done, Pipeline).
- An Initiative is shaped with the CTO.
- The user marks the Task Ready and starts it; starting is always the user's call.

## While work runs

- Agents work the Task's Pipeline.
- The user can write into any running thread; the message lands at the next safe point.
- The user can Stop or Pause a Task.
- The user can open a person's chat to talk something through, and mention any Task, Idea or Decision there.
- Agents consult colleagues when their authority says so.
- The user is asked only when nobody else can or may answer.
- Gates bring the work back for a look (diff, results, screenshots) before it continues.

## Token efficiency

- Every thread shows how its session was continued and what it cost.
- Token efficiency is a primary goal: The Office costs more than manual sessions, so it is as smart as it can be about resuming, starting fresh and handing over.
