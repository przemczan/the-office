# 1. The user's day

- **Morning.** The user opens The Office in the browser. **Now** shows what needs them (Decisions, Gates, messages from people), what is running (Task · person · Stage · time in Stage), what happened since they left, and today's tokens with the 5-hour window. They answer what waits, in place.
- **During the day.** A thought becomes an **Idea** in seconds from the top bar. When it is worth doing, they shape it: into a **Task**, planned in a thread with the Planner (Plan, Definition of Done, Pipeline), or into an **Initiative** with the CTO. They mark the Task Ready and start it; starting is always the user's call.
- **While work runs.** Agents work the Task's Pipeline. The user can write into any running thread (it lands at the next safe point), Stop or Pause a Task, open a person's chat to talk something through, and mention any Task, Idea or Decision there. Agents consult colleagues when their authority says so; the user is asked only when nobody else can or may answer. Gates bring the work back for a look (diff, results, screenshots) before it continues.
- **All the time.** Every thread shows how its session was continued and what it cost. Token efficiency is a primary goal: The Office costs more than manual sessions, so it is as smart as it can be about resuming, starting fresh and handing over.
