Add a Project Proposed

The user's own form for adding a Project, in two steps: Where it is, then the details. Every window keeps its top 7% from the top of the browser window, where the large one already sits, and Add a Project keeps one height, so neither its top nor its bar moves when the source changes. From GitHub gets a list that stays put while it loads and scrolls under a fixed search box, in three designs to compare. Switch the source in the window: dashed lines show where the top and the bar were before the change.

What it proposes

  • Pinned to the top: every window's top sits 7% from the top of the browser window (24px at least), where the large window already sits since it is 86% high and centred. The small one is pinned there too, so the whole app reads the same. Switch Window to “All three, outlined”.
  • One height: Add a Project keeps 640px, or less in a short browser window, as the Stage history keeps its height. Its body scrolls; its head and its bar stay. A short source leaves room under it, which is the price of not jumping.
  • Two steps: step 1 is Where it is: a folder's path then Continue, a git URL then Clone, or a pick from GitHub, which clones at once. Step 2 shows the source as one line with Change, then the form's fields as today. Change goes back to step 1 and forgets the clone, as “Pick another repository” does today.
  • From GitHub: the list is read when the window opens, so it is usually there by the time From GitHub is chosen; while it loads, rows shaped like the list hold its place. Each row shows the repository's name first, then its owner, default branch and when it was last pushed, then its description. A repository already added as a Project is marked Added, can't be picked, and sits at the end under Already added, so the top rows are ones that can be picked. Picking one shows the clone's progress in its row; a failed clone shows its problem in the row, with Try again.
  • Three list designs, to choose one: Recent first (one list, most recently pushed on top), By owner (an owner filter in the list's head, recent first within it) and Search first (the five most recently pushed that aren't Projects yet, with the search reaching all of them).

“Today”, “Proposed”, “Recent first”, “By owner”, “Search first”, “pinned to the top” and “source line” are this design's names, not glossary terms. The mock's data, owners and paths are made up. Like the chat drawer's page, it uses the Geist fonts only where they are installed.
