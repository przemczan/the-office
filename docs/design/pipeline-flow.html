Open choices for Review Design

9 choices Each with the option this proposal recommends. The mock-up below is built on the recommended ones.

  1. Route limit defaults

    Recommended

    A route back starts at 3 and a route on at No limit, and every loop needs a route with a limit.

    Other

    One default of 3 for every route: a route on inside a loop would run out before the route back, and a Gate's Send back would use up the routes on.

  2. An Agent that chooses no route, with no Otherwise

    Recommended

    Ask the user directly, as When no route holds does.

    Other

    The CTO first, then the user.

  3. How Resolve merges the base

    Recommended

    The Agent Stage setting Merge the base first, run by The Office before the Agent's turn.

    Other

    Resolve's brief tells the Agent to call update_branch itself.

  4. Built-in tests on an Agent Stage

    Recommended

    Keep When these hold rows beside the Agent's choices: the move needs them for converted conditions.

    Other

    An Agent Stage has only choices, When it fails and Otherwise.

  5. A Conflict no route takes

    Recommended

    Ask the user directly (resolve in the worktree and Publish again, or drop), as when Resolve gives up today.

    Other

    Treat it as a failure, the CTO first.

  6. Applying a template edit

    Recommended

    Give each chosen Stage only the fields the edit changed, ticking first the Stages that don't differ in them.

    Other

    Give each chosen Stage all the template's fields.

  7. A Broken Project Pipeline at the move

    Recommended

    Copy what still applied, unchoosable until the user saves it once.

    Other

    Copy its base Pipeline as it is now.

  8. A route from a Stage to itself

    Recommended

    Allowed, with its limit: a retry.

    Other

    Refused; go back through another Stage.

  9. The stage runs file

    Recommended

    Version 2, adding the publish kind, a Publish run's result and an Agent's choice.

    Other

    Keep version 1: Publish runs still read as script.
