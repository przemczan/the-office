# Designs

Each file here is an interactive mock-up, one self-contained page you open in a browser. They are drawings for design work only, not the spec: what a screen shows, as built, is its page in [docs/spec/screens/](../spec/README.md#screens), and where a drawing and a screen page differ, the screen page wins.

- [task-page-2.html](task-page-2.html): the Task page (Pipeline rail, Needs you and Before Ready, tabbed record, conversation). Screen page: [Task page](../spec/screens/task-page.md).
- [thread-dialog.html](thread-dialog.html): how a Thread reads (the Rows design, as in a team channel). Screen page: [Thread](../spec/screens/thread.md).
- [chat-drawer.html](chat-drawer.html): the chat drawer. Screen page: [Shell](../spec/screens/shell.md).
- [decision-form.html](decision-form.html): the Decision card. Screen page: [Decision card](../spec/screens/decision-card.md).
- [add-project.html](add-project.html): Add a Project, with Recent first as the GitHub list. Screen page: [Projects](../spec/screens/projects.md).
- [project-appearance.html](project-appearance.html): a Project page's Appearance block (Icon and Logo, with How it looks). Screen page: [Project page](../spec/screens/project-page.md).
- [board-by-initiative.html](board-by-initiative.html): Group by Initiative on the Work board. Screen page: [Work board](../spec/screens/work-board.md).
- [board-initiative-blocks.html](board-initiative-blocks.html): the Work board's columns with Group by Initiative off. Screen page: [Work board](../spec/screens/work-board.md).
- [task-card-icons.html](task-card-icons.html): the Work board's Task card (Foot row). Screen page: [Work board](../spec/screens/work-board.md).
- [initiatives-tab.html](initiatives-tab.html): the Initiatives tab and the Archived tab's Initiatives (the Board). Screen pages: [Initiatives tab](../spec/screens/initiatives-tab.md), [Archived](../spec/screens/archived.md).
- [initiative-page.html](initiative-page.html): the Initiative page. Screen page: [Initiative page](../spec/screens/initiative-page.md).
- [initiative-pipelines-block.html](initiative-pipelines-block.html): the Initiative page's Pipelines block. Screen page: [Initiative page](../spec/screens/initiative-page.md).
- [status-strip.html](status-strip.html): the status strip under the top bar. Screen page: [Shell](../spec/screens/shell.md).
- [sub-agents-and-processes.html](sub-agents-and-processes.html): a session's Sub-agents and Processes line and view. Screen page: [Thread](../spec/screens/thread.md).
- [session-context.html](session-context.html): the context reading above the message input. Screen page: [Thread](../spec/screens/thread.md).
- [loaders.html](loaders.html): the shared loader of a block whose data hasn't arrived yet. Screen page: [Thread](../spec/screens/thread.md); rules: [4.1](../spec/4.1-ui-rules.md).
- [stats.html](stats.html): the Stats page, its two tabs Tokens and cost and System health, and Settings › Telemetry's Stats group. Screen pages: [Stats](../spec/screens/stats.md), [Settings](../spec/screens/settings.md).
- [live-view.html](live-view.html): the Live view. Screen page: [Live view](../spec/screens/live-view.md).
- [live-view-backdrop.html](live-view-backdrop.html): the Live view's whole-office zoom fitting exactly, and five backdrops round the room (glow, diorama, sky backdrop, floor everywhere, floor everywhere with fog of war), by day and night on the Light and Dark themes, with a playground to pan, zoom and change the hour; recommends the fog of war; the user chose the diorama's slab on the floor everywhere, which the screen page describes. Screen page: [Live view](../spec/screens/live-view.md).
- [pipeline-flow.html](pipeline-flow.html): the Pipeline flow editor in Settings › Pipelines and a Project page's Pipelines section. Screen page: [Pipeline flow editor](../spec/screens/pipeline-flow-editor.md).
- [project-pipelines.html](project-pipelines.html): a Project page's Pipelines section and Settings › Pipelines (Built on by, Make it the default, the picker). Screen pages: [Project page](../spec/screens/project-page.md), [Settings](../spec/screens/settings.md).
- [issues-as-tasks.html](issues-as-tasks.html): issues tracked as Tasks: the Kind mark and filter, New Task's Kind, the Task page's Bug and GitHub issue records, the Drop reason, a Project's Default Pipeline per Kind and GitHub issues, Import issues, the Bug Task proposal, with the data model and the order to build it in. Screen pages: [Work board](../spec/screens/work-board.md), [Task page](../spec/screens/task-page.md), [Archived](../spec/screens/archived.md), [Project page](../spec/screens/project-page.md), [Ideas](../spec/screens/ideas.md), [Decision card](../spec/screens/decision-card.md), [Pull requests](../spec/screens/pull-requests.md), [Shell](../spec/screens/shell.md#create).
- [pipeline-editor.html](pipeline-editor.html): Settings › Pipelines' two tabs (Pipelines and Stage templates) and the flow editor's canvas, which pans and zooms, with Fit, the Overview and full screen. Where it differs from pipeline-flow.html, this one wins. Screen pages: [Pipeline flow editor](../spec/screens/pipeline-flow-editor.md), [Settings](../spec/screens/settings.md).
- [project-actions.html](project-actions.html): Project Actions and Project devices: a Project's Actions section (the list, History, the Run window with the Branch picker, the confirm step of an Action that leaves the workstation, a run's log, the Action editor), its Devices section (Add a device, pairing), the Overview's Actions tile, Settings › Office limits' Actions card and the Task page's Use a Project device. Screen pages: [Project page](../spec/screens/project-page.md#actions), [Settings](../spec/screens/settings.md#office-limits), [Task page](../spec/screens/task-page.md#devices).
- [test-instances.html](test-instances.html): Hosted test instances: the Initiative page's Test instances block (Launch, the states, Open, Stop, Log and the refusals), the Log window, Settings › Office limits' Test instances card, the Test instance banner, the hand-off and the proxy's own pages. Screen pages: [Initiative page](../spec/screens/initiative-page.md#test-instances), [Settings](../spec/screens/settings.md#office-limits), [Shell](../spec/screens/shell.md).
- [action-colours.html](action-colours.html): the action tones (go, plan, hold, stop) on the Task page head, the Initiative page head, the Idea card and the More menu, in Version A (coloured icons) and Version B (coloured buttons), in the Light and Dark palettes; built as Version B with the primary buttons' icons toned. Screen pages: [Task page](../spec/screens/task-page.md#head-actions), [Initiative page](../spec/screens/initiative-page.md), [Ideas](../spec/screens/ideas.md); rules: [4.1](../spec/4.1-ui-rules.md).
- [set-up-tasks.html](set-up-tasks.html): Off-board Tasks (Onboard and Set up run environment started at once, off the board) and Set up test targets as a Devops chat: the Project page's Onboarding, Run environment and Test targets cards in each state (Queued, Running, Waiting on you, Failed with Retry, Done, Dropped, Onboard again), the Project Proposal and the Task page's run environment question, Needs you, Now's Running and Queue, Activity, with what stays and the order to build it in. Screen pages: [Project page](../spec/screens/project-page.md), [Projects](../spec/screens/projects.md), [Now](../spec/screens/now.md), [Activity](../spec/screens/activity.md), [Task page](../spec/screens/task-page.md).
- [task-engine.html](task-engine.html): a Task's engine and an Initiative's engine: the engine cascade with its two new levels, the Task page's and the Initiative page's Engine fold (Runs on, Its Tasks, the refusal, read-only once Done), joining and leaving an Initiative and Edit for this Task refused by the capability check, the Project page's Engine note, and the Remove engine window's new rows. Screen pages: [Task page](../spec/screens/task-page.md), [Initiative page](../spec/screens/initiative-page.md), [Project page](../spec/screens/project-page.md#engine), [Settings](../spec/screens/settings.md).

Screens with no drawing (the Project page's Files section, Pull requests, CI runs, Now, People, Account, Sign in) are described only by their screen pages.
