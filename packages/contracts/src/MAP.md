# Contracts: map

**Owns:** the HTTP and WebSocket contract, as zod schemas and their types: the one thing the service and the web share. Also the links to a record's page (`record-links.ts`), which the web writes and the service reads as mentions, and the Project filter's rule (`project-filter.ts`), which the web narrows by and `GET /search` will. Only the service's adapters import it.

**Traps:** an event the web sees needs its schema in the union the web parses, and the service's WebSocket adapter forwarding it ([module template](../../../apps/service/docs/module-template.md)). The files import each other without a cycle: `pipelines.ts` imports `conversations.ts`, so a Stage's schema lives in `stages.ts`, which a Proposal of a Pipeline's Stages names.
