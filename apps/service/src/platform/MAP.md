# Service platform: map

## Owns

- The shared plumbing below every module: config (`GitHubSite`, `addressToOpen`), database (pool with a query observer, `drizzle-calls.ts`, the read scope, fan-out, page SQL), domain events (`EventBus`), earlier-records claims.
- HTTP (`configureHttp`, `OfficeAddresses`, `securityHeaders`, `refuseAmbiguousPaths`, `SignInGuard`, `officeActionRoutes`, `ContractPipe`, `uploadBody`), the event stream and `WebSocketRoutes`.
- The Office data directory, `OfficeTestInstance` (`test-instance/`), `KeyedLocks`, the `Schedule` (`TimerSchedule`, tests' `ManualSchedule`).
- Images rules (`images/`, `imageContent`), files (`resolvedInside`), the office day (`office-day.ts`), the MCP client (`mcp/`, `McpClient`, `startProgram`, `ProgramStdioTransport`).
- The workstation (`workstation/`), the knowledge base (`knowledge-base/`), OS differences (`os/`, `agentShells`), telemetry (`telemetry/`, `BundledGrafana`), System health (`system-health/`), the web app's serving.
- Patterns other maps point to:
  - Paging (`paging/page.ts`, `http/page-cursors.ts`, `database/page-sql.ts`): newest first by `(at, id)`, `PAGE_SIZE` 30, read one past the page (`pageOf`), opaque base64url cursor as `?after=`, an index on `(…, at desc, id desc)`, `{ rows, next, total }`.
  - The read scope (`database/read-scope.ts`): `readOnce(readKey(…), read)` shares one read per key within a GET/HEAD request (`readOncePerRequest`) or `inReadScope`; `forgettingReads(write)` drops the scope's reads.
  - Fan-out (`database/fan-out.ts`): `readEach` reads at most `READS_AT_ONCE` (4) at a time; `onceByKey` shares what items share.

## Talks to

- Nothing above it: modules use it. What a module may use is in the [module template](../../docs/module-template.md). Operating-system differences live only in `os/`.

## Traps

- `EventBus.publish` waits for async handlers (a failing one stops neither the others nor the publisher): a long reaction runs in the background.
- A new fan-out over an unbounded collection goes through `readEach`, never a bare `Promise.all`; a fan-out within each item runs one at a time.
- Reads through `readOnce` are shared: never change one. Every writer of a table read through it (a new writer too) runs through `forgettingReads`. Work a request leaves running inherits its scope until the response closes. A read in a transaction never uses the scope.
- Holds of several rows take them in one order (by id); `retriedTransaction` runs again after a deadlock or serialization failure.
- The pool wrap times only `connect` (wrapping `pool.query` counts twice). drizzle-orm is pinned exactly: `drizzle-calls.ts` patches its builders, `drizzle-calls.test.ts` fails when an upgrade moves one.
- A `WebSocketRoutes` handler owns its client's messages; a throw closes it with 1011. A thread-scoped type reaches only subscriptions scoped to its payload's `threadId`; unscoped gets nothing, silently.
- The sign-in guard judges by the route Nest matched, never the path; open routes are `@OpenWithoutSignIn()`.
- Agents' shells come from `agentShells`: on Windows Git Bash as Claude Code finds it, never a `bash.exe` on PATH (WSL's); PowerShell by `-Command`, not `-EncodedCommand`.
- Start a user-named program through `startProgram` (cross-spawn), never the SDK's stdio transport; `ProgramStdioTransport` ends the tree and waits for `close` (at most 2 s). A local MCP server gets no Office variables. Test MCP servers are `mcp/fake-*.fixtures.ts`.
- A test checking a process ended later than right after uses `isMarkedRunning` with a `processMark` (Windows reuses ids within a second).
- `TimerSchedule` waits for a running job in `beforeApplicationShutdown`, before the database closes. `OFFICE_UPDATE_FOLDER` is set by the launcher alone.
- The bundled Grafana starts or stops only from `office.ts` and the telemetry routes; tests bind `ScriptedBundledGrafana`. It touches only `the-office-grafana`; without its compose file `state()` is `absent` with no Docker call.
- Own endpoint's Grafana address and token apply at once, outside `TelemetryInEffect`.
- Metric attributes are names with few values, never ids (spec §5.2). A test reading a log record's trace after an await needs `AsyncLocalStorageContextManager`.
- `resolvedInside` is how a folder's file is read: a link an Agent planted never reads as the folder's own.
- `officeDayOf`/`officeDayBounds` are the one definition of the office day.
- A `ToWebEvent` may give undefined, keeping an event inside the service. The web app's files are served by middleware (System health counts them Unmatched).
- `KnowledgeBaseModule` is global, held by `AppModule` and every test app.
