# Run environments: module map

**Owns:** run environments (spec §5.5 "Run environments", §5.3 Defaults): reading and validating a worktree's Run environment definition (`.devcontainer/devcontainer.json`, JSONC, and the compose files it names; `RunEnvironments.definitionOf`, every problem in the UI's words for 7967e64c to show as they are); each Project's image, `the-office/<project>:<key>`, built once per key (the definition folder's files, the install command, the Install inputs' contents: `imageKeyOf`) over the definition's image or its own Dockerfile (`the-office/<project>-base:<key>`), with the install command run on a copy of the Install inputs in `/office-install`; each Task's compose project (`office-<instance>-<task>`): the Office's compose file over the repository's (`<office-data>/run-environments/tasks/<task>/office-override.yaml`: the worktree bind-mounted at its own path, the labels on every service, network and volume, the limits on every service), up at the Task's first check (`prepare`, or `run` when it isn't running), stopped after 10 idle minutes and started again at the next check, removed with its volumes and orphans, then by label, when the Task is Done or Dropped; a check run in the checks' service (`run`: `/bin/sh -c` in the worktree, the Project's environment applied, output appended to the caller's file as it comes, the exit code returned); Run environments at once (`RunEnvironmentSlots`: a running run environment holds a slot, first come first served, `onWaiting` told once before a wait; one check at a time per Task, so commands at once never pass it either); the Office-wide limits and Run environments at once (`run_environment_settings`, the spec's defaults until Settings saves them: 2 CPUs, 4096 MB, 1024 processes, 2 at once); the startup sweep (`sweep`, started by `office.ts`).

**Talks to:** the container runtime's compose CLI (`ComposeCommandLine`, Docker Engine with Compose, `docs/container-runtime.md`) behind `ContainerRuntime`; Work's `TaskService` behind `KnownTasks` (bound in [app.module.ts](../../app.module.ts)) for the sweep, and Work's `TaskStateChanged` to `done` or `dropped` for removal, in the background since the bus waits for its handlers; counts building and running as Office-updates' `BusyWork` (`run-environment`). Callers (Pipelines' Script Stages and the environment check, the Agents' Office tool; Tasks 72807e9a and after) pass a `TaskInWorktree`: the Project's install command and Install inputs come from them, so this module needs nothing of Projects.

**Traps:**

- Everything carries `office.instance`, a digest of the Office data directory, and the sweep and every removal look only at this instance's: the tests', the e2e service's and The Office's own share one runtime. Don't sweep by `office.managed` alone.
- The sweep runs from `office.ts`, never `onApplicationBootstrap`, so a test app never asks the runtime for anything; `remove` asks it only for a Task that has a folder or a running environment.
- Compose reads `$` in any compose file as a variable: a value The Office writes into the override goes through `composeLiteral`.
- The override is applied over the repository's files, which compose merges, so a definition setting its own limits, ports, container name, host mounts, privileges or an external network or volume is refused rather than merged (`readDefinition`); devcontainer.json's `workspaceFolder` is read but unused, as the spec mounts the worktree at its own path.
- Ending `compose exec` leaves the command running in the container: a timed-out or stopped check restarts the checks' service.
- Running state, slots and builds in progress are in memory: the startup sweep stops every open Task's run environment so the slots start empty.
- The image sweep keeps the newest image of each Project, standing in for "the image no Project's current key uses" until a Project's current key is known here; an image a container still uses is kept by the runtime.
- `compose-command-line.test.ts` runs on the real runtime when one answers (pulls `busybox:1.37.0`), and is skipped with the reason otherwise.
