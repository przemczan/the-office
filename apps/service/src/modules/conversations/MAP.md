# Conversations: module map

**Owns:** Threads, each one engine session (`threads`, `thread_messages`), and The Office's message log; Decisions as cards in the asking Thread (`decisions`); the Context policy (resume, fresh, hand off, the Brief, Handover notes); the sessions behind Stage Threads (`ThreadRunner`); tokens per Thread and per Task (`TaskTokens`).

**Talks to:** calls Engine, People (`RoleCards`) and Skills (session skills). Reads Project bases through its `ProjectBases` port, bound to Projects' `BaseCheckouts` in [app.module.ts](../../app.module.ts). Work fills `TaskThreadSetups` as it starts, with what a Thread on a Task works with, since Work calls Conversations. Pipelines and Work reach it through ports bound to `StageThreads`, `StageDecisions`, `ThreadRunner`, `ThreadService` and `DecisionService`.

**Traps:** only `application/thread-runner.test.ts` leaves Threads answering, and it alone recovers interrupted answers ([testing](../../../docs/testing.md)).
