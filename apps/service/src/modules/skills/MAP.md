# Skills: module map

**Owns:** the skill library (`skills`, `skill_versions`): uploads, skills written in place and skills installed from a Source at a pinned version (`SkillLibrary.install`; `SkillSources` reads what a Source holds), off until reviewed, "everyone"; its updates (`SkillUpdates`): the daily check that marks an installed skill "Update available" (on the platform's `Schedule`, first run at start), an update's draft and diff (`GET /skills/:name/update-diff`, git's diff between the two pinned versions), and applying one, which keeps the skill on or off and is refused when stale; Role skills (`role_skills`, `role_skill_changes`); Project skills; each session's plugin folder (`SessionSkills`, `session_skills`), in `<office-data>/sessions/<session id>/skills/`; `forget` and `sweep` remove the session's whole folder, with what an engine keeps there to resume it (the OpenAI-compatible API's `conversation.json`).

**Talks to:** no module; People, Projects and Conversations call it (Conversations' `SkillInstallProposals` and `SkillOfficeTools` install from a Source). The Engine takes the folder it builds and never reads Skills. Sources' git repositories, over the network, through `SourceFetcher`, each git command on the Office identity (`GitIdentityModule`; the Source's URL resolved by `ls-remote --get-url` first, since the user's `insteadOf` may turn https into ssh) (`git ls-remote`, a one-commit fetch into a temp bare repository, read from git's objects without a checkout).

**Traps:** a skill on and for everyone reaches every session prepared on the shared test database, so only `application/session-skills.test.ts` turns one on ([testing](../../../docs/testing.md)). Tests never reach a real Source: they use local bare repositories (`adapters/git/source-repository.fixtures.ts`). A Source's repository comes from a model's Proposal, so `sourceRepositoryProblems` admits only https, ssh, `git@` and file URLs and `GitSourceFetcher` pins git's transports and never lets it prompt. The update check reads every installed skill's Source: a Source it can't read is logged and skipped, never an error; a test that runs it reads only its own Sources (`ownSources`, [testing](../../../docs/testing.md)).
