# Skills: module map

**Owns:** the skill library (`skills`, `skill_versions`): uploads and skills written in place, off until reviewed, "everyone"; Role skills (`role_skills`, `role_skill_changes`); Project skills; each session's plugin folder (`SessionSkills`, `session_skills`).

**Talks to:** no module; People, Projects and Conversations call it. The Engine takes the folder it builds and never reads Skills.

**Traps:** a skill on and for everyone reaches every session prepared on the shared test database, so only `application/session-skills.test.ts` turns one on ([testing](../../../docs/testing.md)).
