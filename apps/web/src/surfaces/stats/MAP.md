# Stats surface: map

**Owns:** the Stats page (`/stats`, between Projects and the Live view on the rail, icon `chart-column`; spec 2.11, [the design](../../../../../docs/design/stats.html) is its UI spec). Only the basic stats are built: `stats-page.tsx` draws four blocks on a 12-column grid, each a `Card` in a `section` named by its `h3`, with `BlockLoader` until the first answer and an `Alert` on a failed read:

- **Tokens per day**, "Office-wide": the 30 office days stacked by kind (input, output, cache writes) as inline SVG, one tab stop with ← → (Shift for ten), Home and End stepping a day's `Tooltip` (all four kinds and its total), the cache reads in a strip of their own under it, and Show as a table (`DataTable`). The head is two `TokenCount`s, so totals leave cache reads out (`countedTokens`).
- **The Tasks with the most tokens this week**: each title a link to its Task, its `ProjectChip`, its tokens and a bar against the first row's; the hint that only Stage runs count.
- **Usage windows now**, "Office-wide": each engine whose windows are `read` or `not-read` (`none` isn't listed), each window a meter toned by the strip's `usageTone`, "Not read yet" while unread.
- **This week**: Tasks done and Stage retries, "since Mon 16 Nov" from `weekStartsAt`.
- **The message** at the foot, by Settings › Telemetry: Off, an own endpoint (no Grafana read address can be given yet) or set by the environment, each linking to `/settings/telemetry`; none with Bundled Grafana chosen, whose states and the full stats are later Tasks.

The "Office-wide" badge carries a `Tooltip`, "The Project filter doesn't narrow this…", only while a Project filter is set. Every word is in `stats-words.ts`; `stats.css` draws with tokens only.

**Talks to:** `api/telemetry.ts`'s `statsQueries.basic(filter)` (`GET /stats/basic`, one `project` per Project the filter shows, read again every minute) and `telemetryQueries.settings()`; `projectQueries.list()` for the chips; the shell's `useProjectFilter`, `TokenCount`, `tokensShort`, `ProjectChip`, `BlockLoader`, the strip's window words (`usageTone`, `meterFilled`, `percentWords`) and `time.ts`.

**Traps:** an office day (`YYYY-MM-DD`) is worded in UTC, so it never shifts with the browser's time zone; the resets and "since" are instants, worded in the browser's. A Tooltip reads its size through `ResizeObserver`, which the page test stubs for jsdom.
