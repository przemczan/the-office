# Now surface: map

**Owns:** Now, the home the user opens first: Needs you (the shell's `NeedsYouFeed`, the Task page's Decision and Gate cards under each Task's title and Project chip, and The Office's one Stand-in choice card for every Stage waiting for a Stand-in Engine), Running, the Queue (shown while a Task is queued, each with its place and reasons), Shaping (shown while an Initiative is in Shaping, oldest first: its name opening its page, its Projects, who holds Shapes Initiatives or "Nobody shapes Initiatives yet", its Tasks so far and how long it has been shaped), Since you left and today's tokens, nothing else; above them while the fire alarm is on, its panel (`alarm-panel.tsx`: stopping, on, and "Before the all clear" with Resume / Hold / Drop per Task and the total of those resuming), Office-wide whatever the Project filter shows. All of it comes from the one `now` query, which `now.changed` replaces whole, but for Since you left, each user's own, from `GET /now/since-you-left` (`nowQueries.sinceYouLeft`, read again on each `now.changed`; the status strip's "done since you left" reads it too), and the queued Tasks' Usage estimates, read from Work's `GET /usage-estimates` (the shell's `UsageEstimateLine`), and what each Needs you card reads for itself: its Task, a Gate's Stages and changes, a Decision's Thread and Attachments. The Project filter narrows the feeds (an Initiative with no Tasks yet always shows), each with its "in other Projects" note; desks and tokens stay Office-wide. It reads the service through `src/api/` (see [the web app's map](../../MAP.md)).
