# Now surface: map

**Owns:** Now, the home the user opens first: Needs you (the shell's `NeedsYouFeed`), Running, the Queue (shown while a Task is queued, each with its place and reasons), Since you left and today's tokens, nothing else; above them while the fire alarm is on, its panel (`alarm-panel.tsx`: stopping, on, and "Before the all clear" with Resume / Hold / Drop per Task and the total of those resuming), Office-wide whatever the Project filter shows. All of it comes from the one `now` query, which `now.changed` replaces whole, but for the queued Tasks' Usage estimates, read from Work's `GET /usage-estimates` (the shell's `UsageEstimateLine`). The Project filter narrows the three feeds, each with its "in other Projects" note; desks and tokens stay Office-wide. It reads the service through `src/api/` (see [the web app's map](../../MAP.md)).
