# Work surface: map

**Owns:** the Work board, Ideas (shaped into a Task or an Initiative), Initiatives (the tab's cards with progress, `initiatives-list.tsx`; the Initiative page, `initiative-page.tsx`: the Task graph across Projects, `task-graph.tsx`, laid out in `initiative-words.ts`, blockers outside it dashed; its record and its Threads with the CTO), and the Task page: the record (Overview, Changes), planning, run controls, Stage rows, its dependencies (added and removed before it starts; the board's "Blocked by"), the "Edit for this Task" dialog (the shell's Stage editor on the Task's copy, and the Pipeline swap before Start), the Gate block and the Task's conversation. A Task's and an Initiative's page share the Threads beside the record (`record-threads.tsx`), Attachments, the origin Idea and the missing-record view. It reads the service through `src/api/` (see [the web app's map](../../MAP.md)).
