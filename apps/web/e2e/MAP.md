# Web end-to-end tests: map

**Owns:** the Playwright tests and what they share: `serve-office.ts` starts the built service on the scripted engine, `office-database.ts` reaches the e2e database (for seeding what the UI can't yet make), `office-data.ts` is the fixed e2e Office data directory, `temporary-repository.ts` makes a Project's repository, and `sessions.jsonl` holds the scripted sessions.

**Traps:** the scripted engine hands out `sessions.jsonl`'s scripts in the order sessions open, across files running in parallel, so every test that opens sessions lives in `people.e2e.ts`, the one serial file, its script in order. The e2e files share one database, so titles must differ across files (`getByRole` matches substrings).
